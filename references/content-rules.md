# 内容写作规范（生物医学精读幻灯片）

核心理念：听众（导师/博后）**看图、看趋势，不看数值**。幻灯片承载骨架与结论，
细节数值留在讲者口头和原文档中。

## 1. 实验页四段结构

每个实验页固定四块信息（来自用户 DOCX，需压缩改写）：

| 区块 | 内容 | 篇幅 |
|---|---|---|
| 为什么做 | 该实验在证据链中的动机，排除了什么替代解释 | 1–2 条 |
| 做了什么 | 方法一句话：样本/处理 → 检测手段 → 对照设置 | 1–3 条 |
| 结果分析 | 实验组 vs 对照组的趋势对比（见 §2） | 1–3 条 |
| 结果意义 | 一句话 takeaway（底部高亮条） | 1 句 |

- 每条 bullet ≤ 30 字；写不下就拆条或删修饰语
- 关键术语（方法名、细胞名、关键分子）加粗

## 2. 趋势对照式表达（强制）

结果只写**变化方向**，不写具体数值、倍数、P 值：

- **对照句式**：`对照组状态 vs 处理组状态` 或 `处理前 → 处理后`
  - ✅ "肝内铁阳性细胞：大量 → 几乎消失 ↓↓"
  - ✅ "归巢率：全部归巢 vs 归零 ↓↓ vs 全部归巢"
  - ❌ "从 1200 cells/mm² 降至 50 cells/mm²（P ≤ 0.001）"
- **箭头**：↑ 增多/增强、↓ 减少/减弱、↓↓ 近乎消失/剧变、→ 转变、≈ 无差异
- **颜色编码**（用 deck_kit 的 run 样式）：
  - `"rb"`（砖红加粗）：处理组的变化、本实验的关键结论
  - `"bl"`（海军蓝加粗）：对照组、阴性结果、"无显著差异"
  - `"n"`：中性叙述
- 唯一例外：计数本身的**有无/全或无**（如"全部归巢 → 无一归巢"）属于趋势，可以写

## 3. 实验编号（强制连续）

全篇实验从 **实验 1** 连续编到 **实验 N**，跨 Results 章节/Figure **不重置**。
听众靠编号感知进度，重置编号会被误认为内容重复。

## 4. 分隔页规则

- 按**原文 Results 小标题**设立（不按 Figure 机械切分——以原文正文归属为准，
  例如某 panel 若在上一节正文中被讨论，就归上一节）
- 内容：中译小标题（大）+ 英文原题与 Fig 范围（小、斜体）+ 本节核心问题 + 实验导读
- **不放任何结果图**（后文实验页出现同图时听众会误解为重复/讲错）
- 底部证据链进度条高亮本节所属环节

## 5. 图片规则

- 图是页面主角，`experiment_slide` 已做自适应最大化，不要缩小图去迁就文字
- caption 一行写清：Fig 编号 + 各 panel 要点 + （如有）颜色图例说明
- 图注中保留原文 panel 字母（A/B/C…），方便听众对照原文

## 6. 结构页规则

- **背景页**：共识 → 未解问题（≤3 个，卡片式）→ 本文一句话答案（高亮框）
- **证据链总览**：3–6 个环节 chevron 横排，每环节下注明 Fig 范围 + 一句话
- **总结页**：逐环节一行结论 + ✓，呼应总览页
- **机制模型页**：垂直流程图（5–7 框），末框用强调色
- **讨论页**：创新点 / 局限与未解 / 组会讨论问题 三栏（讨论问题最受导师欢迎）
